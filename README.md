# 📄 Noviq - Smart Document Scanner & PDF Toolkit

Noviq is a modern Android document scanner and PDF toolkit developed by **Shelembe Studios**. It combines powerful document scanning, OCR, PDF utilities, and QR code tools into a clean and intuitive mobile experience.

Designed with speed, simplicity, and productivity in mind, Noviq helps users scan, edit, organize, and share documents directly from their mobile device.

---

## ✨ Features

### 📄 Document Scanner

* Automatic document edge detection
* Manual crop adjustment
* Image rotation
* Multiple document filters

  * Original
  * Auto Enhance
  * Grayscale
  * Black & White
* Export as PDF
* Export as Image

### 📑 PDF Tools

* Merge multiple PDF files
* Split PDF pages
* Compress PDF documents

### 🔍 OCR (Optical Character Recognition)

* Extract text from scanned documents
* Copy extracted text
* Share extracted text

### 📱 QR Scanner

* Scan Website QR codes
* Scan Email QR codes
* Scan Phone QR codes
* Scan Wi-Fi QR codes
* Scan Text QR codes
* Smart actions based on QR content
* Flashlight support
* Scan history
* Paste QR content from clipboard

### 🎨 QR Code Generator

Generate QR codes for:

* Websites
* Email addresses
* Phone numbers
* Wi-Fi networks

Additional features:

* Live QR preview
* QR colour themes
* Save QR as image
* Share generated QR codes
* Input validation
* Smooth animations

## 🚀 Getting Started

### Clone the repository

```bash
https://github.com/sphesihleshelembe/MyApps.git
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npx expo start
```

### Run Android

```bash
npx expo run:android
```
